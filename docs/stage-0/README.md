# Stage 0 — SAPIEN Academy Requirements and Architecture Baseline

This document set records the approved Stage 0 decision package for SAPIEN-OS.

It acts as the product, architecture, data, and brand baseline before implementation begins.

## Scope

This stage establishes:

1. Requirements Traceability Matrix
2. Final Architecture Decision Record
3. Approved Data / Module Plan
4. Mock-data isolation plan
5. SAPIEN Design Token plan
6. Stage 1 implementation plan

The current repository prototype is treated as a demo artifact only. The authoritative source of truth is:

- The SAPIEN Academy product requirements provided in the current brief
- The official uploaded SAPIEN logo
- The requirement to preserve the current code only where it is valuable, but not to preserve prototype decisions when they conflict with the specification

## Decision

Proceed to approval checkpoint for Stage 0. No major implementation work starts until these documents are reviewed and approved.
